# Saroh Web Application

A lightweight, clean client-side web application dedicated to modular utility processing and sleek front-end presentation.

## 🚀 Features

* **Minimalist Component Layout**: Highly structured project layout engineered for rapid load performance.
* **Optimized Client-side Architecture**: Executes completely inside modern browsers with no database prerequisites.
* **Modern UI Styling**: Built on neat typographic patterns and fluid modern web standards.

## 🛠️ Tech Stack

* **Structure**: HTML5 (`index.html`)
* **Styling**: CSS3 (`style.css`)
* **Interactions**: Vanilla JavaScript (`app.js`)

## 📂 Project Structure

```text
├── index.html   # Document structure and application entry point
├── style.css    # User interface layout guidelines, custom properties, and themes
└── app.js       # Dynamic event handlers and logical processing scripts
```

## ⚡ Getting Started

### Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Aravindhan30/saroh.git
   cd saroh
   ```

2. **Launch**:
   * Double-click `index.html` to instantiate the interface locally in your web browser.
